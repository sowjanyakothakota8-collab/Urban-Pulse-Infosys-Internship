Urban Pulse – Smart City Mobility Intelligence Platform

Infosys Springboard Virtual Internship

Welcome to my Infosys Springboard Virtual Internship project repository. This repository documents my work across four milestones focused on urban mobility analytics using Microsoft Power BI.

Project Overview

Urban Pulse is a smart city mobility intelligence platform designed to analyze transportation demand, transit performance, mobility equity, and urban mobility trends through interactive dashboards and visual analytics.

Technologies Used

- Microsoft Power BI
- Power Query
- DAX
- Excel / CSV
- Data Analytics & Visualization

Project Milestones

Milestone 1 – Data Integration & Data Modeling

Data acquisition, data cleaning, standardization, and data modeling.

Milestone 2 – Geospatial & Transit Analytics

Mobility demand visualization, geographic analysis, and transit performance analytics.

Milestone 3 – Demand Intelligence & Mobility Analytics

Ride-hailing analytics, micromobility analysis, and demand intelligence.

Milestone 4 – Equity, Forecasting & Finalization

Mobility equity analysis, forecasting, anomaly detection, and executive intelligence dashboards.

Repository Structure

- "Milestone-1"
- "Milestone-2"
- "Milestone-3"
- "Milestone-4"

Each milestone folder contains its corresponding project deliverables, subject to file availability and sharing permissions.

Learning Outcomes

- Data cleaning and transformation
- Data modeling and Power BI relationships
- Dashboard creation and data visualization
- Mobility analytics and KPI development
- Data-driven insights and reporting
